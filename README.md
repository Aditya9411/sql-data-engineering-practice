# SQL Data Engineering Practice 🚀

This repository contains my hands-on SQL practice for Data Engineering
and SQL technical interviews.

The goal is to strengthen SQL problem-solving skills by working through
real-world and company-based interview questions.

## 🎯 Topics Covered

- SELECT, WHERE & CASE WHEN
- GROUP BY & HAVING
- Joins
- Subqueries
- CTEs
- Window Functions
- ROW_NUMBER(), RANK() & DENSE_RANK()
- Aggregations
- Date & Time Functions
- Data Cleaning
- Deduplication
- Running Totals
- Advanced SQL
- Data Engineering SQL Patterns
